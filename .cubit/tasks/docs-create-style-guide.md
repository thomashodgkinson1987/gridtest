# Task: Create Initial Style Guide

-   **Goal:** To create a central `STYLE-GUIDE.md` document that records all of our established project conventions for code, Git, and documentation.
-   **Type:** `docs`
-   **Priority:** High
-   **Branch:** `docs/create-style-guide`

---

## Action Plan

1.  **Create File:** Create a new file named `STYLE-GUIDE.md` in the project's root directory.
2.  **Add Initial Content:** Populate the file with the conventions we have already discussed and agreed upon during our sessions. Key topics to include are:
    *   **Language:** US English for code, British English for prose.
    *   **Terminology:** Official spellings for common terms (`codebase`, `workflow`, etc.).
    *   **Git Commits:** Reference the Conventional Commits specification, our subject line guidelines (50/72 rule, imperative mood), and scope naming conventions (`cmdsys`).
    *   **Formatting:** Our 80-column limit for C code.
    *   **File Naming:** `snake_case` for code, `dash-case` for metadata.
3.  **Commit:** Commit the new style guide directly to the `develop` branch with a `docs(project): Create initial style guide` message.
